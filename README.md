# Resort-Business
The application will have a home page to list out the very recent 3 products.  The product listing page lists out only 5 products on a single page and requires a pagination feature to shore more products in the next pages. Each product offering will have a name, Descriptions &amp; multiple images.   The product listing page shows only the Product name and one image. Selecting the image or name will take the user to the product details page where the name, description, and all the images under the product are listed.  A logged-in user will be able to comment on the product and all the previous comments received for the product will be listed out in the comment section on top of the comment listing.  The resort will need an admin interface to create and publish the products and view the comments created under each product.
